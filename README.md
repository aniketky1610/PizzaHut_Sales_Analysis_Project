🍕 PizzaHut Sales Analysis

📌 Project Overview

This project focuses on analyzing PizzaHut sales data to generate meaningful business insights. It demonstrates a complete data analysis workflow, from querying raw sales data to building an interactive dashboard for decision-making.

The project uses MySQL for data analysis and extracting insights, and Power BI for creating interactive visualizations and dashboards.

---

🎯 Objectives

* Analyze overall sales performance and revenue trends  
* Identify top-selling pizzas and categories  
* Understand customer ordering patterns  
* Analyze hourly and daily order trends  
* Support data-driven business decisions  

---

🛠️ Technologies Used

* MySQL  
* Power BI  

---

🔄 Project Workflow

### Data Analysis (MySQL)

* Wrote SQL queries to analyze sales performance  
* Used joins, aggregations, and subqueries for insights  
* Identified important business metrics  
* Analyzed revenue, order trends, and pizza performance  

Data Visualization (Power BI)

* Created an interactive dashboard  
* Visualized key performance indicators (KPIs)  
* Analyzed revenue trends and sales performance  
* Enabled easy exploration of business insights  

---

📊 Key Insights

* Identified top-selling pizzas and categories  
* Analyzed total revenue and sales trends  
* Discovered peak ordering hours and customer behavior  
* Evaluated category-wise sales performance  
* Measured revenue contribution of pizza types

🚀 How to Run the Project

1. Clone this repository  
2. Import the dataset into MySQL  
3. Execute SQL queries for analysis  
4. Open the Power BI file to view the dashboard  
5. Explore insights and business trends

📌 Dashboard

The Power BI dashboard provides an interactive view of PizzaHut sales insights, helping users quickly understand revenue trends, top-performing pizzas, customer ordering patterns, and category-wise performance.

This project showcases how sales data can be transformed into actionable insights using MySQL and Power BI. It highlights the importance of data analysis, querying, and visualization in understanding business performance and supporting better decision-making.
